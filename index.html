Cafe24 → Cello Square 주문 변환기

Cafe24 주문 내역 CSV를 업로드하면 Cello Square 주문업로드 양식(xlsx)으로 자동 변환해 다운로드합니다.

1 기본값 설정

Cafe24 주문 데이터에는 없지만 Cello Square 업로드에는 필요한 값들입니다. 화주/상품군별로 자주 쓰는 조합을 프리셋으로 저장해두고 불러올 수 있습니다.

2자리 국가코드, 예: JP
Cafe24에 이메일이 없어 필수값 대체용
전 행 고정값 (BL열)
{상품번호} 자리에 Cafe24 상품번호가 자동으로 들어갑니다 (AZ열)

2 Cafe24 주문 CSV 업로드

Cafe24 주문조회 화면에서 다운로드한 CSV 파일을 그대로 올려주세요.

📄 클릭하거나 파일을 끌어다 놓으세요

3 변환 결과 확인 후 다운로드

Article(상품) 기준 행 미리보기입니다. 다운로드 전 필수값 누락 여부를 확인하세요.

다운로드된 파일은 Cello Square 정식 업로드 양식(Delivery Order Format)과 동일한 컬럼 구조입니다. 업로드 전 Email / HS Code / 박스 사이즈 등 실제값을 다시 한 번 확인하세요.
